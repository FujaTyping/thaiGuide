**ThaiGuide API** Backend API for the ThaiGuide platform a gamified travel experience that encourages travelers to explore new destinations across Thailand through missions, QR check-ins, points, and rewards.
This API powers the ThaiGuide ecosystem including the mobile/web app, dashboard, and gamification systems.

## 📃 Environment Variables
Create a `.env` file
```
APIKEY=
AUTHDOMAIN=
PROJECTID=
STORAGEBUCKET=
MESSAGINGSENDERID=
APPID=
MEASUREMENTID=
TYPHOON_APIKEY=
GOOGLE_GENAI_API_KEY=
IMAGEKIT=
IMAGEKIT_PUBLIC=
JWT_RAND=
DSGHOOKS=
```

## 🧭 Vision
ThaiGuide aims to reduce tourist overcrowding in major cities and encourage travelers to explore hidden destinations across Thailand through gamification.
By turning travel into a game, we help distribute tourism opportunities and support local communities.
